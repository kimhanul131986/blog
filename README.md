# Nixie Blog Studio

한 줄짜리 주제와 선택 자료를 입력하면 네이버 블로그용 제목, 본문, 사진 구성, 태그를 생성하는 로컬 웹 앱입니다.

## 실행

```powershell
npm start
```

브라우저에서 `http://localhost:4173`을 엽니다.

API 없이도 **프롬프트만 복사** 기능을 사용할 수 있습니다. 앱 안에서 바로 원고를 생성하려면 `.env.example`을 복사해 `.env` 파일을 만들고 키를 입력하세요. `.env`는 Git에서 제외됩니다.

```powershell
Copy-Item .env.example .env
notepad .env
npm start
```

API 키는 브라우저에 전달되거나 저장되지 않습니다. 서버는 생성 결과를 OpenAI에 저장하지 않도록 `store: false`를 사용합니다.

## 동작 방식

- 주제 한 줄을 바탕으로 글 유형 자동 선택
- 실제 경험과 확인된 정보 분리
- 제목 5개, 원고, 사진 배치, 태그 생성
- 대표·본문 보조 이미지 프롬프트 자동 생성
- API 연결 시 GPT Image 2로 세로형 보조 이미지 생성 및 PNG 저장
- 사용자 프로필과 기존 글 샘플은 브라우저 `localStorage`에 보관
- 확인되지 않은 경험, 가격, 효능 및 고객 반응 생성 금지

실제 판매 상품의 사진은 직접 촬영해야 합니다. AI 이미지는 레시피나 보관법 같은 보조 장면에만 사용하고 발행할 때 AI 생성 이미지임을 표시하세요. 이미지 API 사용에는 별도 비용이 발생합니다.
